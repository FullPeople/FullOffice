# 新建、演示文稿与独立文字识别验证

开发版新增首页的新建文档、表格、演示文稿和 Markdown 笔记入口。当前创建流程先选择文件名和位置，再打开编辑器；没有实现未命名文档流程。新文件使用独立暂存文件，校验后发布；覆盖已有文件时保留备份，目标发生外部修改或已在当前窗口打开时拒绝替换。

PPTX 已接入独立原生编辑器、原文件保存、备份、格式校验和恢复列表。演示模板由 python-pptx 1.0.2 生成，保留 MIT 许可证；测试依赖没有进入应用运行目录。DOCX 和 XLSX 的空白包由应用直接生成。

## 无系统中文语言包时的文字识别

缺少 Windows 中文识别语言时，改用随软件提供的识别组件；已有中文语言时仍使用 Windows 识别。备用组件在独立进程中运行，按需加载官方中文与英文模型，并核对模型摘要。图片与结果仅暂存于独立请求目录，结束或取消后清理，不上传。

- 强制备用组件的完整功能检查 22 项通过，包含实际中文识别与剪贴板复制、书签编辑、复制图片、悬停标记和多个置顶区域。
- 七项独立识别检查通过：真实子进程启动后取消、确认退出、取消清理、损坏模型故障隔离、随后中文识别成功、图片和正文暂存清理、PDF 原文件摘要保留。总耗时约 2.21 秒，不作为单次 OCR 的速度指标。
- 包内 .NET 包版本为 Tesseract 5.2.0；实际 Windows 原生库报告 Tesseract 5.0.0、Leptonica 1.82.0，不能将两者都写成 5.2.0。模型与全部所报告图像库的许可、来源及摘要已记录在 `licenses/ocr` 和 `ocr-data`。
- 云端检查强制运行备用组件，完整中文 OCR 断言继续保留，不再等待 Windows 更新服务下载语言组件。Windows 原生中文识别的既有本机验收与备用组件验收分别记录。

上游依据：[Windows 语言组件依赖](https://learn.microsoft.com/windows-hardware/manufacture/desktop/features-on-demand-language-fod)、[Tesseract .NET 5.2.0](https://www.nuget.org/packages/Tesseract/5.2.0)、[官方快速识别模型](https://github.com/tesseract-ocr/tessdata_fast/tree/87416418657359cb625c412a48b6e1d6d41c29bd)。

这仍是基础演示文稿、基础新建和识别组件验收，不替代复杂演示稿兼容性、完整新安装包、跨设备或 macOS 验收。自动保存、更多常见格式及完整发行仍须继续完成。
