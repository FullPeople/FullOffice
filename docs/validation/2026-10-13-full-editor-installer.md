## 长路径修复和实际安装

首轮完整安装失败：日本语模板的文件名加上用户临时目录后长达 278 个字符，超过传统 Windows 路径限制。旧候选没有通过安装验收。

安装器改用经过规范化的 Windows 扩展路径处理文件与父目录，并在安装、更新组件中声明长路径支持。原有链接、范围、重复路径、大小和完整性检查保留。34 项边界与登记检查通过，包含超过传统长度的中文资源路径。

随后完整单文件安装、内置运行环境、已安装应用的 Markdown／文本功能、正常卸载、卸载临时程序清理、用户资料保留和默认登记移除七项通过；已安装应用内部 15 项文本检查也通过。测试放在 C 盘独立目录以保留 D 盘空间，测试安装已正常卸载。

这些检查证明完整候选安装和基本运行，不代替通过已安装副本再做 DOCX／复杂 Excel／PPTX 的编辑、性能和视觉验收。
