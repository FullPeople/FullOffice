# macOS 开发候选与验证范围

macOS 候选使用原生 AppKit／PDFKit 阅读窗口。PDF 支持原有书签层级和位置跳转、连续／单页模式、整页／适宽、系统文字选择与复制。Office 编辑组件只在打开相应文档时启动，运行在独立进程。完整自包含包使用固定版本的 ONLYOFFICE 组件；测试在移除上游磁盘挂载后运行，验证应用从自身包内加载组件。

DOCX／XLSX 已实际验证原生输入、公式计算、写回当前文件、保留上一版备份，以及未保存关闭时的保存／取消／丢弃。文件替换前校验暂存内容；外部修改冲突或保存失败时保留编辑副本。恢复入口只按用户请求读取已结束会话，通过系统保存窗口导出新的恢复文件，并在实际原生编辑器中重开正文。

Markdown／文本使用原生文本编辑器，支持查找、撤销／重做、保存、另存和退出选择。UTF-8、带 BOM 的 UTF-8／UTF-16LE／UTF-16BE 与原换行格式已有验证。Markdown 预览在点击后加载独立模块，支持标题、表格、代码和本地图片，原始 HTML 按文字显示。远程图片目前显示占位提示。

当前安装候选的应用使用 ad-hoc 签名，安装包尚无 Apple Developer ID 签名或公证。编译目标为 macOS 13；实际云端运行环境为 macOS 15，实体 macOS 13 和首次下载的系统确认界面尚未验证。包体使用既有应用图标生成 icns，随附主体、原生组件及第三方声明。

待完成的 Mac 范围包括 PDF 原文件保存、注释与书签编辑、常驻彩色页签、区域悬停／地图小窗、多标签页与最近记录的完整交互、更多 Office 格式和复杂工作簿，以及完整公网更新流程。测试文件独立生成；用户文档、正文、曲库、设置和凭据均不进入源码、云端测试或发布包。Windows 的功能表和验收结果分别记录，官网 Mac 下载入口将在具体包体与发布范围核对后更新。
