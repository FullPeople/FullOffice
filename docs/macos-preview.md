# macOS 原生阅读移植

当前独立开发分支实现原生 AppKit／PDFKit 阅读窗口：PDF 打开、完整原有书签层级及目的地跳转、连续与单页模式、整页与适宽、系统文字选择和复制。书签仅在打开文件后解析，不启动 Windows 编辑器，不扫描用户文档。

这是只读研究预览。PDF 写回、注释和书签编辑、彩色页签、区域小窗、Markdown、完整 DOCX／Excel 编辑及重算、安装卸载和签名更新尚未移植。不能将它作为完整 FullOffice 的 Mac 发行版，也不据此启用官网 Mac 下载按钮。

两种 Mac 架构在云端分别编译自己的原生程序；不是将 Windows EXE 重命名。使用既有应用图标生成 icns。包体只有本项目 Swift 代码、图标和 MIT 声明，使用系统 AppKit／PDFKit；临时的 ad-hoc 签名不等于 Developer ID 签名或公证。

验证使用独立生成的三页 PDF，检查原文书签和文字、页面跳转、缩放、真实窗口显示和窗口图像，前后文件摘要保持一致。e3ecfcc 的两架构原生基础 8 项通过，但 NSView 缓存图像不能证明页面像素。89383a1 和 b594529 已捕获真实系统合成窗口，人工检查可见正文和蓝色标示；原生色彩取样仍为零。独立 PNG 解析在同一图像检测到 9,600 个匹配像素，因此改用固定版本的独立图像读取器，并保留同一 500 像素门槛，不据旧基础检查宣称全部视觉验收通过。最新完整 9 项结果待云端返回；不包含用户 PDF 或实体设备性能验收。
